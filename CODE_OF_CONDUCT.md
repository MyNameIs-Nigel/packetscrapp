# Code of conduct

Be respectful, constructive, and welcoming. Critique ideas and code, respect different experience levels, and assume good intent while taking reported harm seriously.

Harassment, discrimination, threats, sexualized conduct, doxxing, and repeated personal attacks are not acceptable in issues, pull requests, or other project spaces.

Report a concern privately to a repository maintainer through a contact method listed on their GitHub profile. If none is available, request a private contact in an issue without publishing sensitive details. If the concern involves a maintainer, contact another maintainer where possible; this project does not currently have an independent moderation team.

Maintainers may remove content, warn participants, restrict participation, or ban contributors based on severity and recurrence. Reports should be handled discreetly and without retaliation.
