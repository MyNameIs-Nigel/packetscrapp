# Security policy

## Supported versions

There is no deployed or supported application release yet. Once releases begin, security fixes will target the latest stable release; development builds are not supported for public hosting.

## Report a vulnerability

Use GitHub's **Security → Report a vulnerability** for private reporting when enabled. Include affected versions, reproduction steps, impact, and a suggested fix if known. Do not post secrets, player information, or working exploits in public issues.

If private reporting is unavailable, open an issue requesting a private contact without disclosing the vulnerability. A maintainer will establish a private channel. Response times are best effort; this is a volunteer project.

Only test systems you own or are explicitly authorized to test. Do not flood public game servers or interrupt other players. Maintainers should reproduce in development, rotate exposed credentials, prepare a regression test, and coordinate a patched release before public disclosure.
